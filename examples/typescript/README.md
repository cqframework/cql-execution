This mini-project demonstrates using `cql-execution` from TypeScript. It depends on
the repository's local `cql-execution` package and owns its TypeScript tooling.

From the repository root, install and build `cql-execution`:

```sh
npm install
```

Then install and run the example:

```sh
cd examples/typescript
npm install
npm start
```

Run `npm run typecheck` to type-check the project and `npm test` to execute its
automated test.
